# Socio-Technical Alignment & Sycophancy Diagnostic

## 📌 Project Overview
This research prototype identifies **AI Sycophancy** and **Power Differential Mediators** within digital educational environments. It uses a cross-modal sentiment analysis to detect the "Dissonance Gap" between formal institutional compliance and informal affective reality.

## 🧠 Key Methodology
- **Formal vs. Informal Contexts:** Distinguishes between institutionally mandated "Text-Only" discourse (Formal) and emoji-rich affective signaling (Informal).
- **Institutional Breach Detection:** Monitors when users bypass social norms (e.g., inserting symbols into formal reports) as a high-priority signal of distress or rebellion.
- **Sycophancy Probability:** Calculates the likelihood that high formal performance is merely a "performative mask" masking latent friction.
- **Power Mediation:** Tracks irony as a subversive tool for collective student alignment against rigid authority structures.

## 🛠 Tech & Conceptual Design
- **Language:** Python
- **Framework:** Socio-Technical Impact Assessment (STIA)
- **Note:** This project demonstrates the application of **Prompt Engineering** to translate complex social science theories into functional technical diagnostics. It serves as a bridge between AI Ethics research and data-driven monitoring.
